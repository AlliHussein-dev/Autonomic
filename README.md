# Autonomic site

Static one-page site: Vite + React + Tailwind v4 + Framer Motion. No backend, no accounts, no tracking.

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # outputs dist/

Edit placeholders in `src/lib/site-config.ts` (booking link, founder photo, demo videos, optional email and WhatsApp number).
Demonstration copy lives in `src/components/site/Demonstrations.tsx`.
