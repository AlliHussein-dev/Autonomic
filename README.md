# AUTONOMIC

AUTONOMIC is an AI automation business that helps companies save time, capture more leads, and streamline operations through AI voice agents, website chat agents, and automated follow-up workflows.

## Tech Stack

- Vite
- React
- Tailwind CSS v4
- Framer Motion

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

The production build is generated in the `dist/` directory.

## Configuration

Edit `src/lib/site-config.ts` to configure the booking link, founder photo, demonstration videos, email address, and WhatsApp number.

Demonstration content is managed in `src/components/site/Demonstrations.tsx`.

## Project Overview

A responsive, dark-themed, single-page website showcasing AUTONOMIC's AI automation services, workflow demonstrations, business benefits, and contact options.
